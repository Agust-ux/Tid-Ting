# TechDocs/api.md

# API Dokumentasjon

## Hente prosjekter

```http
GET /api/projects
```

### Opprette prosjekt
```http
POST /api/projects
```

### Oppdatere prosjekt
```http
PUT /api/projects/:id
```

### Slette prosjekt
```http
DELETE /api/projects/:id
```

### Hente oppgaver
```http
GET /api/projects/:id/tasks
```

### Opprette oppgave
```http
POST /api/tasks
```
